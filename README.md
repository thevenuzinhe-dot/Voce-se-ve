# Você se vê?

Experiência artística de pausa, presença e autorreflexão.

## Baixar para Android

[**Baixar o APK mais recente**](https://github.com/thevenuzinhe-dot/Voce-se-ve/releases/latest/download/Voce-se-ve.apk)

No Android, abra o arquivo baixado. Na primeira instalação, o sistema pode pedir autorização para instalar aplicativos do navegador. A câmera é solicitada somente quando a experiência chega ao momento do retrato.

Também existe uma [página simples de download](https://thevenuzinhe-dot.github.io/Voce-se-ve/download.html).

## Privacidade

As respostas, a assinatura e a fotografia não são enviadas. A fotografia existe apenas temporariamente durante a experiência. O aplicativo funciona sem internet; a conexão é usada somente quando a pessoa decide abrir no celular a mensagem mostrada pelo QR Code.
